# Friends Plans
Static friend form + private dashboard (GitHub Pages) backed by a private Google Sheet via Apps Script.
- `index.html` – friend form (edit link = `index.html#t=<token>`)
- `admin.html` – Rodrigo's dashboard (asks for admin key, stored only in browser localStorage)
- `config.js` – Apps Script web-app URL (not secret). Backend code is NOT in this repo.
